The kitchen math layer for your AI assistant.

recipe-mcp is a local Model Context Protocol server. It gives Claude — or any MCP client — reliable tools for unit conversion, ingredient weight⇄volume, recipe scaling, baker's percentages, and a private cooking assistant powered by your own Ollama models.

What it does

Five things LLMs are bad at doing in their head — made exact.

⚖️

Unit conversion

Weight (mg · g · kg · oz · lb · stone) and volume (ml · l · cup · tbsp · tsp · fl oz) with US, metric and imperial variants.

🧂

Weight ⇄ volume

A bulk-density table for ~28 common ingredients. “How many grams is 1 tbsp of salt?” when your scale isn't precise to the gram.

📐

Scaling

Rescale a whole recipe by a factor or by changing the yield — 8 servings to 12 — keeping every amount in proportion.

🥖

Baker's percentages

Flour = 100%, everything relative to flour. Read a formula from a recipe, or turn a formula into weights for any batch size.

🧮

Ratios & percentages

Solve ratios like 3:2:1 from a total or one known amount, and express any ingredient list as a share of total weight.

🤖

Local assistant

Ask cooking questions answered by an Ollama model running on your machine. Configurable model, host and temperature.

Install & run

Python 3.10+. Needs Ollama only for the assistant tools.

# clone & set up
git clone https://github.com/mnavas/recipe-mcp
cd recipe-mcp
python3 -m venv .venv && source .venv/bin/activate
pip install -e .

# a model for the assistant
ollama pull gemma3n

# run the server (stdio)
python -m recipe_mcp
// register with an MCP client
{
  "mcpServers": {
    "recipe": {
      "command": ".venv/bin/python",
      "args": ["-m", "recipe_mcp"],
      "env": {
        "RECIPE_MCP_MODEL": "gemma3n:latest"
      }
    }
  }
}

A private cooking assistant

The assistant tools call Ollama on your own hardware — nothing is sent to a cloud API. Point it at any installed model.

# ask (via your MCP client)
cooking_assistant(
  question="Why weigh flour instead of cups?"
)
# → "Cup measures vary with how flour is
#    packed; weighing in grams is consistent."
# configure once
set_config(
  model="llama3.1",
  temperature=0.3,
  persist=true
)
